# Contributing

Keep My Good Day gentle, accessible, and focused on small acts of care.

1. Follow the setup in [README.md](README.md).
2. Make application changes in `code/`, product documentation changes in
   `docs/`, and reusable skill changes in `skills/my-good-day/`.
3. Run `pnpm test` and `pnpm build` from the repository root.
4. Check affected flows in the browser. For interaction changes, include
   keyboard use and a narrow screen; for diary changes, check saving,
   reloading, photos, and deletion.
5. Describe the change and what you checked in your pull request.

Preserve task IDs, the green/orange capsule meanings, optional notes/photos, the completion requirement,
and the browser-local diary unless the change explicitly addresses them.
Use original or appropriately licensed assets. Never commit credentials,
personal diary entries, photos, dependency directories, or generated builds.

See [development notes](docs/development.md) for the source map and
[design brief](docs/Design.md) for product context.
